    65→   264→   264→[]{#_Toc100005 .anchor}**3.3 The First Message to the AI Builder**
    66→   265→   265→
    67→   266→   266→After the documents are loaded and the context file is in place, the
    68→   267→   267→builder issues the first message to the AI builder. The first message is
    69→   268→   268→the prompt that starts the build, and it follows the master prompt
    70→   269→   269→template that the next section presents. The first message establishes
    71→   270→   270→the builder\'s role, specifies the system to build, directs the builder
    72→   271→   271→to consume the relevant document sections, and begins the three-phase
    73→   272→   272→model. The first message is the most consequential prompt in the build,
    74→   273→   273→because it sets the context and the expectations for everything that
    75→   274→   274→follows, and a poorly constructed first message will produce a build
    76→   275→   275→that drifts from the specification.
